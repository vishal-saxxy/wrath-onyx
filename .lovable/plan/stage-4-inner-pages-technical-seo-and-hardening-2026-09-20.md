# Stage 4: Inner pages, technical SEO and hardening

## Build

- Centralise every supplied inner-page string in typed content data; keep guide bodies absent and log all missing inputs.
- Replace each temporary inner route with the shared dark introduction, one supplied signature visual where required, structured light reading sections, and the identical closing action block.
- Reuse the existing answer, evidence, radial, surface-bar and governed-record visual language; add no new visual primitive and leave the homepage markup and copy unchanged.
- Keep every page below seven viewport heights, with only the measurement page eligible for one pinned section.

## Technical details

- Add unique route metadata, self-referencing canonical declarations once the canonical host is supplied, and only the specified structured data.
- Make diagrams single labelled images, hide decorative SVGs, and provide parallel button lists for interactive diagram controls.
- Configure crawler access and generate the sitemap only when a canonical public host is available.
- Record the missing guide bodies, share image, canonical host, logo/favicon and legal copy in the build notes.

## Verification

- Check every route at the fixed desktop canvas with JavaScript enabled and disabled.
- Validate headings, landmarks, focus, contrast, greyscale meaning, route height, metadata and structured data.
- Run strict compliance scans across served source and public files, then measure loading, layout stability and compressed initial JavaScript.
